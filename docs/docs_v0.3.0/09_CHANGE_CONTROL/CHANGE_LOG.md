# Change Log — Almudaya Multi-Agent v0.3.0

Catatan kontrol perubahan arsitektur, ruang lingkup, dan kebutuhan untuk versi 0.3.0.

| Change ID | Tanggal | Deskripsi | Alasan | Dampak | Keputusan |
|---|---|---|---|---|---|
| **CHG-301** | 2026-11-03 | Inisiasi Baseline v0.3.0 | Menambahkan Interactive Bot Console REPL (`almudaya bot run`) dan Cross-Root Location-Aware Session Work Log | Meningkatkan UX terminal agar bot all-in-one tanpa terminal freeze, serta memungkinkan orkestrasi koding multi-root terpadu | Disetujui (Approved) |
| **CHG-302** | 2026-11-03 | Menyelesaikan Phase 2 System Analysis & Architecture Design | Menyusun SYSTEM_ANALYSIS, DATA_FLOWS, SYSTEM_DESIGN, merumuskan ADR-301 dan ADR-302, menyelesaikan OI-301 dan OI-302 | Fondasi arsitektur REPL non-blocking, rendering ANSI non-destruktif, dan skema memori kerja lokasi presisi | Passed Phase 2 Gate |
| **CHG-303** | 2026-11-03 | Implementasi Phase 3 Shared Session Work Memory Engine | Mengimplementasikan `WorkLogService`, `WorkLogEntrySchema`, `IWorkLogStorage`, metode append/read atomik, dan 16 test unit komprehensif | Menyediakan repositori memori kerja persisten `work_log.jsonl` untuk multi-root tanpa data loss atau line corruption | Passed Phase 3 Gate |
| **CHG-304** | 2026-11-03 | Implementasi Phase 4 Interactive Bot Console REPL | Mengimplementasikan `BotConsole`, parser slash commands, rendering ANSI non-destruktif, integrasi Human-in-the-Loop review, dan 17 test unit | Mewujudkan konsol terminal all-in-one tanpa freeze, menghilangkan kebutuhan membuka terminal ekstra untuk komunikasi bot | Passed Phase 4 Gate |
| **CHG-305** | 2026-11-03 | Integrasi Phase 5 ReAct Loop & Context Prompt Injection | Mengimplementasikan tool AI `get_work_log`, injeksi Markdown memori kerja ke system prompt, pencatatan otomatis tool execution ke `work_log.jsonl`, dan 8 test baru | Menghubungkan penalaran AI ke memori kerja bersama sesi untuk kesadaran situasional tim dan koding lintas-root | Passed Phase 5 Gate |
| **CHG-306** | 2026-11-03 | Verifikasi Phase 6 End-to-End Multi-Root Verification Benchmark | Menyusun pengujian integrasi tolok ukur lintas-root `tests/e2e/multi-root-orchestration.test.ts` membuktikan kolaborasi Architect, Coder, dan Tester di 2 root berbeda | Membuktikan secara empiris keandalan pencatatan presisi, penemuan dependensi via get_work_log, dan penegakan Invariant 5 | Passed Phase 6 Gate |
