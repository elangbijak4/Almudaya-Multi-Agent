# Almudaya Multi-Agent — Project Blueprint

This archive contains the master coding-agent prompt and the v0.1.0 Waterfall documentation baseline.

1. Place `MASTER_PROMPT.md` in the repository root.
2. Place the `docs/` directory in the repository root.
3. Open the repository in Codex, Antigravity, OpenCode, or another coding agent.
4. Ask the agent to read `MASTER_PROMPT.md` and execute its **First task**.
5. Review environment preparation and any system-level installation before approving it.

The documents are a starting baseline. Environment facts must be measured, and open design decisions must be resolved before implementation.
