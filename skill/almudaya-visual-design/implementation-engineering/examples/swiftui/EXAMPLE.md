# Example: SwiftUI Mapping

Scenario: an iOS companion application.

- Map AVDS semantic roles to dynamic asset colors and system typography.
- Use native navigation, sheets, alerts, and controls where appropriate.
- Support Dynamic Type, VoiceOver, Reduce Motion, and light/dark appearance.
- Avoid fixed dimensions that break with larger text or localization.
- Verify on representative iPhone and iPad layouts if both are targets.
