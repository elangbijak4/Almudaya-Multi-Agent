# Cross-Platform Test Case Catalog

Use these test ideas as a starting point; tailor expected results to the approved requirements.

| ID | Area | Test |
|---|---|---|
| AVDS-QA-001 | Task clarity | Can a target user identify the primary task and next action? |
| AVDS-QA-002 | Navigation | Can users reach and return from major sections without losing context? |
| AVDS-QA-003 | Responsive | Does the layout adapt without clipping or priority inversion? |
| AVDS-QA-004 | Keyboard | Can all essential actions be completed without pointer input? |
| AVDS-QA-005 | Focus | Is focus visible, logical, and correctly managed in overlays? |
| AVDS-QA-006 | Screen reader | Are controls and status changes exposed with meaningful semantics? |
| AVDS-QA-007 | Contrast | Do text and controls meet the applicable contrast requirements? |
| AVDS-QA-008 | State | Are loading, empty, error, success, and disabled states clear? |
| AVDS-QA-009 | Recovery | Can users recover from validation and network errors? |
| AVDS-QA-010 | Platform | Does navigation and input behavior follow declared platform conventions? |
| AVDS-QA-011 | Content | Do long labels, localization, and large text avoid breaking layout? |
| AVDS-QA-012 | Visual regression | Are unintended changes to hierarchy, spacing, and component states detected? |
| AVDS-QA-013 | Modality | Are essential actions available through supported alternatives? |
| AVDS-QA-014 | Safety | Are consequential actions scoped, confirmed, and recoverable where appropriate? |
| AVDS-QA-015 | Evidence | Can each pass/fail result be traced to reproducible evidence? |
