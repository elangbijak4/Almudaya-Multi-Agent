# Cross-Platform UI/UX Audit

Audit each target separately for task success, platform navigation, interaction modality, feedback, error recovery, readability, accessibility, performance, and visual consistency. Record test device/emulator, viewport, input method, and actual evidence. Never claim a platform is tested when only source code was inspected. Escalate safety-critical automotive and industrial interfaces for domain-specific expert review.
