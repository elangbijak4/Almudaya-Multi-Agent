# Platform Implementation

Read the selected platform profile, interaction skills, design brief, and existing project stack. Map semantic tokens to platform primitives; do not transplant DOM components to native stacks. Implement platform-native navigation, focus, gestures, state, errors, and adaptive layouts. Preserve functional behavior. Validate using available platform tooling and label untested targets explicitly.
