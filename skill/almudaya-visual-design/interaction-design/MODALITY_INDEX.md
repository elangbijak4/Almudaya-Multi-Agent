# AVDS Interaction Modalities

- `mouse-pointer` — hover, selection, drag, precise targeting
- `keyboard` — focus order, shortcuts, command navigation
- `touch` — tap, swipe, press, scroll
- `stylus` — precision drawing, pressure and handwriting
- `voice` — speech input, spoken output, confirmation
- `gesture` — body/hand gestures and sensor input
- `gaze-spatial` — gaze, raycasting, spatial anchoring
- `remote-dpad` — directional focus, select, back
- `haptic` — tactile confirmation and alerts
- `multimodal` — combine available modalities based on task and context
