# Component Composition Patterns

## Navigation
- Global navigation + local navigation
- Contextual navigation scoped to a selected object
- Step navigation for finite workflows
- Search/command navigation for expert workflows

## Data
- Table + row detail inspector
- Map + layer controls + feature inspector
- Timeline + event detail
- Chart + evidence/source panel
- Master-detail list
- Compare view with aligned attributes

## Forms and transactions
- Single-purpose form
- Progressive disclosure form
- Multi-step transaction with review
- Inline editing with explicit save/cancel semantics
- Validation summary linked to invalid fields

## Workspace
- Canvas/editor + contextual inspector
- Document + outline/navigation
- Terminal/log stream + command controls
- Multi-pane workspace with user-adjustable boundaries

## Content and learning
- Reading column + contents navigation
- Lesson sequence + progress + practice
- Reference content + worked example
- Media + transcript/captions + controls

## Operational systems
- Alert queue + incident detail + runbook
- Status overview + drill-down evidence
- Safe action panel with confirmation and rollback context

Do not apply a pattern solely because a component is familiar. Verify its task fit and platform conventions.
