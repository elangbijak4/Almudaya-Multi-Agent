# Visual Quality Audit
Review style fidelity, distinctiveness, hierarchy, typography, color semantics, layout, responsive behavior, component states, accessibility, and functionality. For each issue report severity, page/component, evidence, expected behavior, and fix. Do not invent screenshot findings. If only source code was inspected, label the report code review rather than rendered visual audit.
