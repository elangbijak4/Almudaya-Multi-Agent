# Benchmark Decision Guide

After repeated baseline and AVDS runs:

- **Adopt AVDS workflow** when improvements are consistent across task fit, composition, platform adaptation, and contract fidelity without unacceptable regressions in accessibility or implementation quality.
- **Refine AVDS** when design quality improves but implementation time, contract friction, or agent compliance degrades materially.
- **Narrow AVDS scope** when only certain product classes benefit.
- **Inconclusive** when runs are too few, environments differ, or evidence is insufficient.

Do not set a universal numeric pass threshold before seeing pilot variance. Establish thresholds after the pilot and document why they are meaningful.
