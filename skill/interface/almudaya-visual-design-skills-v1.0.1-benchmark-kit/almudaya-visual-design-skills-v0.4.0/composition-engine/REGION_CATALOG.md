# Region Catalog

| Region | Purpose | Typical contents |
|---|---|---|
| Global shell | Persistent product frame | Brand, global navigation, account |
| Primary navigation | Move between major areas | Tabs, rail, sidebar, bottom navigation |
| Local navigation | Move within a section | Section menu, table of contents |
| Work surface | Main task execution | Editor, map, canvas, form, table |
| Context inspector | Explain or modify selected object | Properties, metadata, evidence |
| Filter/query region | Refine visible data | Search, facets, date range, layers |
| Status/feedback | Communicate system state | Progress, alerts, validation |
| Command region | Invoke actions | Command palette, toolbar, action menu |
| Detail region | Inspect an entity | Detail pane, profile, record |
| Learning guidance | Support comprehension | Hints, examples, walkthrough |
| Collaboration | Coordinate people/work | Comments, presence, activity |
| System utility | System-level controls | Settings, help, connectivity |

Only include regions that support a user task or system requirement. Region names describe responsibilities, not mandatory visual containers.
