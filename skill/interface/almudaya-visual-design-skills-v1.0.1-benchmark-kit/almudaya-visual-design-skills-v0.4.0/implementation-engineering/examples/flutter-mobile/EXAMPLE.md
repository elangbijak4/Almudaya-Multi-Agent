# Example: Flutter Mobile Mapping

Scenario: a field-research app used outdoors.

- Use high-legibility text and controls appropriate for touch and sunlight conditions.
- Support offline/poor-network states and explicit sync status.
- Use platform-appropriate navigation and system back behavior.
- Make location permission rationale clear; request permissions in context.
- Do not make color the only indicator of risk or status.
- Test text scaling, TalkBack/VoiceOver, orientation, and interrupted workflows.
