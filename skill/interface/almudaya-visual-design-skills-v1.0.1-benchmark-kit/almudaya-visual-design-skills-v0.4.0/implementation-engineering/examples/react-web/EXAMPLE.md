# Example: React Web Mapping

Scenario: a research dashboard with a map, filters, and analysis results.

- Use semantic `main`, `nav`, `form`, `button`, and labeled controls.
- Treat the map as a primary workspace only if spatial exploration is the core task.
- Provide a keyboard-accessible alternative to map-only operations (search by place, table/list of features).
- Use CSS custom properties mapped from the AVDS semantic token contract.
- Ensure filter changes have perceivable status feedback and do not unexpectedly steal focus.
- Test keyboard navigation, narrow viewport composition, zoom, and reduced motion.

This is an implementation checklist, not a claim that a working React app is included.
