# Platform and Modality Selection

Create a target matrix with: platform ID, screen and form factor, environment, input devices, output channels, primary tasks, critical states, accessibility requirements, performance limits, and platform-specific safety rules.

Select profiles using explicit project targets. If unspecified, do not assume every platform. Ask one question when the platform materially changes the implementation.

Modality mapping must include primary input, secondary fallback, system feedback, failure recovery, and discoverability. For high-risk domains, document review owner and unresolved constraints.
