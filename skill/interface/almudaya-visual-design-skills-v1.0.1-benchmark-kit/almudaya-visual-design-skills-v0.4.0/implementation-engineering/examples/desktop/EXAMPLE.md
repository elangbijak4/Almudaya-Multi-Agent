# Example: Desktop Workspace Mapping

Scenario: a multi-panel research and engineering tool.

- Inspect the current native toolkit before choosing controls.
- Support resizable windows, keyboard shortcuts, focus traversal, menus, and file operations.
- Provide a clear information hierarchy for dense panels.
- Use virtualization for large datasets.
- Ensure destructive commands have confirmation or undo/recovery.
- Verify high-DPI scaling, window resizing, and keyboard-only operation.
