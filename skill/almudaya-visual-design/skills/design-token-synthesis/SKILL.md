# Design Token Synthesis
Inspect existing tokens first. Preserve brand tokens. Define semantic color roles (canvas, surface, text, muted text, border, actions, focus, success, warning, danger); typography roles; spacing/grid; radii; borders; elevation; motion; and all interaction states. Use the project's native format. Check contrast and do not claim compliance without testing. Avoid arbitrary one-off values. Validate against the token schema when tooling is available.
