# Changelog

## [1.0.1] - 2026-11-08
### Added
- AVDS Integration & Benchmark Kit for controlled baseline vs AVDS-assisted evaluation.
- Three benchmark scenarios: Almudaya Academy, Almudaya Quantum Lab, and Geospatial Fire Intelligence.
- Experimental protocol, scoring rubric, anti-generic design checklist, run prompts, report template, and run schema.
- Decision guide for interpreting benchmark outcomes.

### Notes
- This is a benchmark specification release, not a report of completed application tests.
- No Antigravity/Codex integration run or UI evaluation is claimed by this package.

## [1.0.0] - 2026-11-08
### Added
- Unified Orchestrator coordinating intake, design, composition, implementation, QA, and delivery.
- Design-to-Code Contract with lifecycle states, artifact dependencies, and invariants.
- Implementation Manifest schema for stack, component mapping, deviations, and evidence.
- Agent Handoff Protocol and handoff envelope schema.
- Change Impact Workflow and design decision governance.
- Contract validation checklist and consistency governance rules.
- Updated Antigravity, Codex, and generic-agent adapters.
- Full-cycle delivery manifest example.

### Release notes
- v1.0.0 establishes the unified framework and artifact contracts.
- Specialist skills remain modular and can be invoked independently.
- The release is agent-instruction and schema driven; it does not include a universal autonomous runtime, automatic code generator, or built-in browser/device test runner.
- Existing visual style profiles, platform profiles, composition resources, implementation guides, and QA protocols are retained.

## [0.6.0] - 2026-11-08
### Added
- Cross-Platform QA Engine skill and evidence-based QA workflow.
- Visual review, interaction testing, accessibility audit, and platform conformance protocols.
- Cross-platform test case catalog, finding template, and release gate.
- JSON Schemas for QA reports and individual test cases.
- Illustrative QA report demonstrating explicit coverage limitations.
- Root orchestrator integration from implementation to quality assurance.

### Notes
- QA protocols are agent-executable instructions and templates; they do not themselves run browser/device automation.
- QA status must reflect actual evidence. Missing evidence is `not_assessed`, never an assumed pass.

## [0.5.0] - 2026-11-08
### Added
- UI Composition Engine workflow for task-first, platform-aware interface planning.
- Page archetype and composition pattern library covering 14 structural approaches.
- Layout grammar, region catalog, component composition patterns, and adaptive composition rules.
- JSON Schemas for Composition Plan and semantic Component Tree.
- Example composition plans for web GIS, mobile learning, and desktop quantum research.
- Composition audit skill and a minimal fixture.
- Root orchestrator integration connecting composition planning to implementation engineering.

### Notes
- The engine is instruction-driven in this release; no executable layout runtime is included.
- Existing 40 visual styles, 13 platform profiles, interaction modalities, adapters, and v0.4.0 implementation guidance are retained.

## 0.4.0
- Added platform implementation engineering workflow.
- Added native component mapping and interaction contracts.
- Added cross-platform semantic token contract.
- Added implementation guidance for React, Flutter, SwiftUI, Jetpack Compose, and desktop stacks.
- Added platform capability/fallback matrix and implementation templates.
- Retained the 40 visual style profiles and v0.3 cross-platform architecture.
