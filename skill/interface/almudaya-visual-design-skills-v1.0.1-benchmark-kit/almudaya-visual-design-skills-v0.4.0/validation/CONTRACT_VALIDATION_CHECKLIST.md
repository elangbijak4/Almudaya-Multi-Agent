# AVDS Contract Validation Checklist

Before implementation handoff:
- [ ] Contract JSON validates against its schema.
- [ ] All referenced artifact paths exist.
- [ ] Artifact IDs and versions are unique and explicit.
- [ ] Dependencies point to valid artifact IDs.
- [ ] Approved constraints are carried into the handoff.
- [ ] Critical composition regions map to component-tree nodes.
- [ ] Component IDs are unique within the tree.
- [ ] Essential actions define modality and feedback.
- [ ] Adaptive variants preserve task priorities.
- [ ] Accessibility considerations are documented.
- [ ] Open assumptions and unresolved questions are visible.
- [ ] Implementation acceptance criteria are testable.

Before release:
- [ ] Implementation manifest exists and records deviations.
- [ ] QA report references the correct contract/build.
- [ ] Blockers are resolved or release is marked fail.
- [ ] Untested scope is explicitly recorded.
- [ ] Decision log and artifact versions are current.
