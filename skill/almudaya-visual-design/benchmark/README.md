# AVDS Integration & Benchmark Kit

This kit evaluates whether AVDS improves real coding-agent UI/UX outcomes rather than merely increasing design documentation.

## Benchmark targets
1. Almudaya Academy — learning and editorial experience, mobile-first adaptation.
2. Almudaya Quantum Lab — scientific visualization and dense desktop workspace.
3. Geospatial Fire Intelligence — map-centric composition and evidence inspection.

## Evaluation modes
- **Baseline:** same task prompt, same agent/model, same stack and constraints, without AVDS.
- **AVDS-assisted:** same task prompt and constraints, with AVDS v1.0.0 skills and contracts.
- **Blind review:** reviewers score anonymized outputs without knowing which workflow produced them, where feasible.

## Important
The repository contains benchmark specifications, prompts, scoring rubrics, and report schemas. It does not claim that Antigravity, Codex, or any generated application has already been run or evaluated.
