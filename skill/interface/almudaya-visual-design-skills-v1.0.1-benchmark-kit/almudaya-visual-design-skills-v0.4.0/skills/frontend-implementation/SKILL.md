# Frontend Implementation
Inspect framework, routes, components, and styling. Read the Design Brief and tokens. Compose pages around user journeys. Reuse suitable project components without forcing unsuitable patterns. Use semantic HTML, accessible controls, intentional responsive behavior, and meaningful empty/loading/error/success states. Respect reduced motion. Test primary user flows and compare rendered output with the brief when browser inspection is available.
