# Antigravity Adapter — AVDS v1.0.0

Use the repository root `SKILL.md` as the main entry point. When the environment supports agent skills, register `unified-orchestrator/SKILL.md` as the orchestration skill and retain specialist skills as callable resources.

## Operating instructions
- Inspect the repository and existing stack before proposing implementation changes.
- Treat AVDS artifacts as design contracts, not as permission to rewrite unrelated code.
- Create or update artifacts in the project's designated AVDS directory.
- Use specialist agent roles for independent analysis, but maintain a single owner for shared contract and global token changes.
- Return paths, versions, validation status, and limitations after each phase.
- Do not claim browser/device tests unless actually executed in the available environment.
