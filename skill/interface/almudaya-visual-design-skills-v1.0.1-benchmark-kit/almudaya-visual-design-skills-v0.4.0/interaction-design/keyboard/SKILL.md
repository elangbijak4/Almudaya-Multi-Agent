# Keyboard Interaction Skill

## Primary interaction patterns
focus order, shortcuts, command navigation.

## Required safeguards
full keyboard access, no traps, shortcut discoverability.

## Integration
Use this skill only after the platform and primary user tasks are identified. Define input, feedback, error recovery, and accessible alternative paths. Do not assume the presence of hardware capabilities without evidence.
