# Composition Workflow

| Stage | Key question | Output |
|---|---|---|
| Intent model | What is the user trying to accomplish? | Task map |
| Information architecture | What information belongs together? | Content groups |
| Archetype | What structural pattern best supports the tasks? | Archetype selection |
| Region composition | Which regions are necessary? | Region map |
| Component graph | How do components relate? | Semantic tree |
| Adaptation | How does structure change by viewport/device? | Adaptive variants |
| Interaction | How are actions performed and understood? | Interaction map |
| Review | Does the composition support real tasks? | Audit findings |

## Decision order
User tasks → information architecture → platform capabilities → interaction modality → composition pattern → visual style expression.

## Required plan metadata
Record the selected archetype, alternatives considered, assumptions, constraints, and unresolved questions. Use `not_applicable` rather than silently omitting a relevant dimension.
