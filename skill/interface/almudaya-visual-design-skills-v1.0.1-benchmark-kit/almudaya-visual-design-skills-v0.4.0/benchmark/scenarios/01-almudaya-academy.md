# Scenario 01 — Almudaya Academy

## Product context
A learning platform for Indonesian students offering structured courses, lessons, assessments, and learner progress.

## Primary journeys
1. Discover a course by topic or learning goal.
2. Inspect course outcomes, prerequisites, and learning path.
3. Enroll or resume a course.
4. Read/watch a lesson and complete a practice activity.
5. Review feedback and continue learning.

## Required screens
- Course discovery
- Course detail
- Lesson learning surface
- Practice/assessment
- Learner progress

## Platform targets
- Web desktop
- Mobile phone
- Tablet

## Design challenge
Avoid treating the product as a generic analytics dashboard. The lesson reading/practice flow should be central. Use an editorial/learning composition and show how the same visual identity adapts to touch-first mobile interaction.

## Acceptance criteria
- Learner can find and resume a course.
- Lesson content has clear reading hierarchy.
- Practice feedback is understandable and recoverable.
- Progress is useful but does not dominate the learning surface.
- Mobile layout is intentionally adapted, not simply shrunk.
- Accessibility alternatives are documented for media and assessments.

## Visual differentiation prompts
Try two distinct style profiles from AVDS that remain suitable for an educational product. Explain the trade-offs and select one for the primary implementation.
