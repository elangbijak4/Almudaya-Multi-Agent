# API Compatibility Matrix (`Phase 0`)

**Target:** All public TypeScript exports (`src/index.ts`), service classes, storage interfaces, CLI commands, and runtime invariants that must remain backward-compatible throughout PKU integration.

---

## 2. Behavioral & Invariant Compatibility Matrix

| Surface / Subsystem | Mandatory Invariant to Preserve | Forbidden Regression | Verification Gate & Test Suite |
|---|---|---|---|
| **`IBlackboardStorage` & `FilesystemSessionStorage`** | All 5 sub-interfaces and on-disk JSON/JSONL paths operate identically when PKU is disabled, unconfigured, or unreachable (`PKU-004`, `PKU-005`). | Requiring a PKU store instance in `new FilesystemSessionStorage()` or mutating legacy files during read-only export. | `tests/session/*`, `tests/bot/*`, `tests/messaging/*`, `tests/shared/*` + new `PKU-004` / `PKU-005` tests. |
| **Session Lock & Storage Fencing (`AUD-09`, `REQ-06`)** | `withSessionLock` increments `.fencing_token` and `verifyStorageFencing` rejects stale fencing tokens (`StaleLockFencingError`). | Performing unsynchronized concurrent mutations to session files or bypassing fencing token checks. | `tests/core/lock.test.ts` (12 tests). |
| **Sender Authentication (`AUD-10`, `REQ-02`)** | `MessagingService.publishBroadcast` and `sendDirectMessage` reject unregistered or non-`active` bot senders while allowing `HUMAN`, `SYSTEM`, `OPERATOR`, `ADMIN`, `CONSOLE`. | Allowing spoofed messages or bypassing `authenticateSender` in memory-aware messaging extensions. | `tests/messaging/broadcast.test.ts`, `tests/messaging/direct-message.test.ts`, `tests/cli/messaging-cli.test.ts`. |
| **Broadcast Cursor & Callback Ordering (`AUD-07`, `REQ-05`)** | `BotRuntime.pollCycle()` reads broadcasts with `autoAdvanceCursor: false` and advances cursor **only after** `onBroadcastCallback` succeeds (`PKU-006`). | Advancing broadcast cursor before callback completion or dropping unconsumed events across category filters. | `tests/messaging/broadcast-cursor-atomic.test.ts`, `tests/bot/runtime.test.ts`. |
| **Direct Message Lease & Fencing (`AUD-08`, `REQ-04`)** | `completeMessage` and `failMessage` verify `consumerId === lease_owner`, non-expired lease, and matching `fence_token` (`PKU-007`). `readInbox` applies `limit` before marking messages `'read'` (`AUD-06`). | Completing/failing a message from a stale worker after lease expiry/reclaim, or marking unreturned paginated messages as `'read'`. | `tests/messaging/inbox-state.test.ts` (16 tests), `tests/messaging/transactional-inbox.test.ts`. |
| **Secret Redaction Boundary (`AUD-11`, `REQ-07`)** | All persisted records, logs, and errors pass through `redactSecrets` / `redactRecursively` (covering regex patterns and `registerSecret` dynamic secrets) (`PKU-008`). | Storing raw API keys, bearer tokens, or dynamically registered secrets in PKU `KnowledgeObject` or `MemoryEvent` payloads. | `tests/security/secret-redaction-canary.test.ts`, `tests/tools/env-sanitization.test.ts`. |
| **Prompt Injection Delimiter Escaping (`AUD-15`, `REQ-10`)** | Untrusted peer messages and work-log summaries are wrapped in `<<<UNTRUSTED_*>>>` delimiters with `escapePromptDelimiters()` escaping embedded `<<<` and `>>>`. | Injecting PKU/KOE retrieved untrusted content into prompts without delimiter escaping and trust-boundary framing. | `tests/security/prompt-injection.test.ts` (8 tests). |
| **Cancellation & Abort Propagation (`AUD-20`, `REQ-12`)** | `BotRuntime.stop()` and `AutonomousAgentLoop.stop()` abort in-flight LLM generation and rate-limit backoff immediately without completing message leases prematurely. | Blocking `BotRuntime.stop()` indefinitely on a hung PKU operation or completing a message when `signal.aborted` is true. | `tests/bot/cancellation.test.ts` (5 tests). |
| **ACG Fail-Closed Governance (`AUD-01`, `AUD-02`, `AUD-04`, `AUD-13`, `AUD-14`, `AUD-16`)** | External filesystem/command access requires authenticated `(sessionId, botId)`, valid scoped grant, supported isolation backend, and mandatory durable audit (`AuditPersistenceError`). | Allowing PKU adapters or lifecycle operations to bypass sandbox/ACG path boundaries or delete files inside target project roots. | `tests/execution/controller.test.ts` (20 tests), `tests/capability/capability.test.ts`, `tests/capability/presets-table.test.ts`. |
